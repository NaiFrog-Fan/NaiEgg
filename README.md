# NaiEgg
奶蛋（NaiEgg）：一只软萌又慵懒的 Codex 原生桌宠，戴着小睡帽、抱着软乎乎的枕头，会迷糊打盹，也会陪你认真工作。
奶蛋保留黄色蛋形身体、绿色圆眼、黄色睡帽、奶白帽边和绒球，抱着奶白色枕头陪你工作。包内含 Codex v2 原生宠物，以及三段独立剧情预览。

双击 `preview.html`，可在浏览器中一次查看所有动作和剧情。此预览页可离线打开。

## 安装

1. 解压 `naiegg-pet.zip`。
2. 在 Codex 设置中进入 **Pets / 宠物**，找到 **Custom Pets / 自定义宠物**，点击 **Open Folder / 打开文件夹**。
3. 将解压后的整个 **naiegg** 文件夹复制进去。文件夹内应直接包含 `pet.json` 和 `spritesheet.webp`，避免再套一层同名文件夹。
4. 返回宠物设置，点击 **Refresh / 刷新**，选择 **奶蛋**。若宠物处于隐藏或休息状态，使用应用里的唤醒或显示入口。

自定义宠物目录通常是 `%USERPROFILE%\.codex\pets`；以应用中“打开文件夹”实际打开的位置为准。此交付未替你安装或激活宠物。

官方说明：[Pets](https://learn.chatgpt.com/docs/pets)。不同版本的设置名称可能略有差异。

## 动作和预览

原生宠物包含九种动作：坐姿打盹、向右小跑、向左小跑、困困挥手、抱枕跳跃、躲进枕头、坐着等你、认真工作、探身检查。另有十六个站立抱枕的注视方向和一个站立正面姿态。

`previews/native/` 中是原生动作动图、注视方向循环，以及待机—跳跃—待机的衔接预览。坐姿自然比站姿矮；原生待机只重复轻微打盹，避免不断放下和拿起枕头。

`previews/stories/` 中有：

| 文件 | 内容 | 时长 |
|---|---|---:|
| `story-sleep.gif` | 放低枕头、坐下靠枕、偷偷睡觉、醒来抱枕起身 | 12 秒 |
| `story-slip.gif` | 枕头滑低、赶紧接住、抱紧、尴尬微笑 | 4 秒 |
| `story-wake.gif` | 打盹、睁眼、揉眼、抱起枕头、站起来继续营业 | 8 秒 |

三段剧情为独立的关键姿势动图，随包交付供观看；它们不会在 Codex 内新增定时睡眠、点击唤醒或自定义剧情触发规则。九种原生状态何时播放由 Codex 决定。

## 文件

- `naiegg/`：可安装的宠物文件夹。
- `previews/`：原生动作、注视方向、三段剧情与动作总览。
- `qa/`：尺寸、透明背景、边缘处理、注视方向和视觉验收记录。

原生动画采用透明 WebP 图集；GIF 预览有调色板限制，安装后以 WebP 原生效果为准。
